What is Networking?
Networking is the connection of differents hosts together to communicate, share and receive resources on a network, example of hosts on a network are: Computers, Phones, Tablets, switches, routers etc.
The TCPIP model layers are as follows:
1. Presentation layer 2. Data link layer 3. Network layer 4.Transport layer 5. Session layer 6. Presentation layer 7. Application layer.
